Provider Enrollment

Overview

The Provider Enrollment Agent guides new providers through a single conversational intake: it collects contact details, NPI and license numbers, specialty and network, and a supporting credential document, then creates an Enrollment record and confirms submission — no phone calls, no paper packets, no manual data entry.

What this agent automates

  • Presents a guided enrollment form immediately, with no chit-chat, when a new conversation starts.
  • Captures First Name, Last Name, Phone, Email, NPI Number, License Number, Specialty, and Network.
  • Accepts a supporting credential document upload (PDF, PNG, or JPEG up to ~4.5MB).
  • Creates an Enrollment__c record and returns a trackable application id.
  • Confirms submission back to the applicant in the same conversation.
